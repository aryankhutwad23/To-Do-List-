# 📝 React To-Do List App

A modern **React-based To-Do List application** designed to help users stay productive and motivated.  
This project demonstrates React fundamentals (state, props, hooks) while adding practical features like editing, completion tracking, and motivational quotes.

---

## 🚀 Features
- ➕ **Add Tasks**: Quickly add new items to your list.
- ✏️ **Edit Tasks**: Update existing tasks inline.
- ✅ **Mark Completed**: Tick tasks off with a checkbox (line-through effect).
- ❌ **Delete Tasks**: Remove tasks you no longer need.
- 📊 **Task Summary**: Displays total, completed, and remaining tasks.
- 💡 **Motivational Quotes**: Random quote shown to inspire users.
- ⌨️ **Keyboard Shortcuts**: Press **Enter** to add tasks faster.

---

## 🛠️ Tech Stack
- **React** (Functional Components + Hooks)
- **CSS** for styling
- **Node.js + npm** for local development
- **Netlify/Vercel** for deployment
